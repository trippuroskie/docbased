<ToolSpec
  name="docbased spaces"
  summary="Enumerate spaces the current caller can read. Service mode returns every space; user mode returns the caller's accessibleSpaceIds."
  returns={<>JSON: <code>{`{ mode, count, spaces: [{ id, slug, name, description }] }`}</code></>}
/>

## Examples

```bash
# JSON for piping into jq or an LLM
npm run docbased -- spaces

# Human-readable
npm run docbased -- spaces --format text
```

ecomm                    Ecomm
it                       IT
